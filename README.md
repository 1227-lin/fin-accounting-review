## 目录结构

```
index.html            首页：倒计时、今日任务、15 章地图
knowledge.html        知识清单：15 章 + 全站搜索 + 已掌握勾选
plan.html             74 天计划表：11 周、每天任务、进度条
cheat.html            考前速查：分录 / 易混 / 公式 / 策略

assets/style.css      全部样式（含打印样式，可直接另存 PDF）
assets/app.js         渲染 + 交互（倒计时、搜索、进度、今日任务）

data/site.js          站点配置：考试日、起算日、书名 ← 只改这里就能改全站
data/ch01-05.js       第 1–5 章知识清单
data/ch06-10.js       第 6–10 章知识清单
data/ch11-15.js       第 11–15 章知识清单
data/plan.js          74 天计划（日期由 app.js 自动推算，不用手填）
data/cheat.js         速查内容
```

## 怎么改

**考试日期变了？** 改 `data/site.js`：

```js
examISO: '2027-01-08T09:00:00+08:00',
examLabel: '2027年1月8日（周五）',
```

计划表里所有日期是从 `startISO` 顺序推算的，考试日改完，倒计时会自己跟着变。

**想加/改某一章？** 改 `data/chXX.js`，一个章节对象长这样：

```js
{
  num: 5, title: '金融资产', alias: '一句话副标题',
  weight: '12–18 分', stars: 5, hot: true,
  oneLine: '一句话讲清这章在干嘛',
  why: '为什么值得学',
  concepts: [{ t: '术语', d: '人话翻译' }],
  entries: [{ name: '分录标题', rows: [{ s: '借', a: '科目', n: '金额' }], note: '备注' }],
  traps: ['易错点'],
  quiz: [{ q: '题目', a: '答案' }],
  mnemonic: '记忆钩子'
}
```

**想调整计划？** 改 `data/plan.js` 里的 `weeks[].days`，加几条就多几天，日期会自动顺延。
